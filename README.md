# AI Project 2 - Data Classification Using AI

## Overview
This project demonstrates a Machine Learning classification model using the Iris dataset. The model is trained to classify iris flowers into different species based on their features.

## Objective
- Load and analyze a dataset
- Split data into training and testing sets
- Train a classification model
- Evaluate model performance
- Make predictions on unseen data

## Technologies Used
- Python
- Pandas
- Scikit-Learn

## Dataset
Iris Dataset (provided by Scikit-Learn)

## Algorithm Used
Decision Tree Classifier

## Project Workflow
1. Import required libraries
2. Load the Iris dataset
3. Split data into training and testing sets
4. Train the Decision Tree model
5. Predict test results
6. Evaluate performance using:
   - Accuracy Score
   - Classification Report
   - Confusion Matrix

## Output
- Accuracy Score: 1.0
- Predicted Values
- Actual Values
- Classification Report
- Confusion Matrix
