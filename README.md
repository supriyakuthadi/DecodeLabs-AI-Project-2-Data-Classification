# DecodeLabs-AI-Project-2-Data-Classification

Overview

This project demonstrates a basic Machine Learning classification model using the Iris dataset. The goal is to train a model that can classify iris flowers into different species based on their features.

Objective

- Load and understand a dataset
- Split data into training and testing sets
- Train a classification model
- Evaluate model performance
- Make predictions on unseen data

Technologies Used

- Python
- Scikit-Learn
- Pandas

Dataset

The project uses the Iris dataset provided by Scikit-Learn. The dataset contains measurements of iris flowers and their corresponding species.

Algorithm Used

Decision Tree Classifier

Project Workflow

1. Import required libraries
2. Load the Iris dataset
3. Split data into training and testing sets
4. Train the Decision Tree model
5. Predict results on test data
6. Evaluate the model using:
   - Accuracy Score
   - Classification Report
   - Confusion Matrix

Output

The model successfully classifies iris flower species and achieved:

- Accuracy Score: 1.0

The program also displays:

- Predicted Values
- Actual Values
- Classification Report
- Confusion Matrix
